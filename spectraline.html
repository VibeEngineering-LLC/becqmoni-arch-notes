1. Назначение и место в линейке LSRM

SpectraLineBG — продукт семейства SpectraLine 1.7 для спектрометрического анализа гамма-бета-спектрометрами, полупроводниковыми и сцинтилляционными. Типовые задачи: сертификация пищевой продукции, минеральных удобрений, стройматериалов, радиационный мониторинг, контроль технологических процессов и загрязнений (БГ стр. 4).

Семейство: SpectraLineGP, SpectraLineBG, SpectraLineHandy, SpectraLineUltimate, SpectraLineADA и др.; документ «Основные функции» общий для всех — «под SpectraLineXX понимается любая программа семейства» (ОФ стр. 9). Собственное руководство BG (13 страниц) описывает только надстройку над общей функциональностью:

  • бета-тракт: тип конфигурации «Бета», первичная калибровка методом «По перегибу», обязательный «поканальный» учёт фона, калибровка по эталонным спектрам; традиционные методы обработки линейчатых спектров для бета-спектров отключаются — доступны только первичная калибровка и шаблонный метод (БГ стр. 5);
  • гамма-тракт: демо-конфигурация Gamma-1S; вся работа — по документу ОФ (БГ стр. 5);
  • шаблонный и квазишаблонный методы расчёта активности с отдельными кнопками инструментальной панели (БГ стр. 8–10);
  • автокалибровка по энергии для бета-конфигураций: подбор линейной калибровки E = aN + b по критерию минимума χ²-функционала относительно эталонного спектра (БГ стр. 7);
  • комплект плагинов: воздух через фильтр (lcalc_airpollution.dll), декларирование нуклидов, протяжённые объекты, выпадения, спецотчёты по нормативам, поверхностное загрязнение (БГ стр. 5);
  • сценарий Th-Calibration для энергетической калибровки по Th-232 (БГ стр. 6);
  • файловая структура: после установки в LSRM\Work появляется папка BG с демо-конфигурациями Beta-1S и Gamma-1S (БГ стр. 10).

Чем BG отличается от Ultimate/GP по составу модулей, в прочитанных документах явно не сформулировано (см. раздел «Не нашёл в доках»).

3. Рабочий цикл обработки гамма-спектра

Обобщённая схема (АО гл. 2; ОФ разд. 3.4) с пунктами меню:

  1. Загрузка: Файл => Открыть спектр (или снимок с анализатора Анализатор => Снимок). Для спектра создаётся локальная копия конфигурации (ОФ стр. 44).
  2. Свойства спектра: Файл => Свойства спектра — живое/реальное время, геометрия, детектор, расстояние, масса/объём образца, материал, выбор кривой эффективности из .efa (ОФ стр. 45–48). Без расстояния источник–детектор расчёт активности недоступен.
  3. Границы обработки: контекстное меню Установить границы обработки (Ctrl+B).
  4. Калибровки (меню Калибровка): - при отсутствии/сильном уходе — Первичная калибровка (интерактивно по 2+ пикам или вручную E=A*Ch+B; сохранение в .cen/.cfw, ОФ стр. 55–59); - Энергетическая калибровка — привязка реперных линий к библиотечным энергиям, ортогональные полиномы по областям, совместная калибровка нескольких спектров, подкалибровка по 1 точке (поворот/смещение), сохранение в .cen (ОФ стр. 59–66); - Калибровка по полуширине — после энергетической; требует пика-образа; сохранение в .cfw (ОФ стр. 66–69); - Калибровка по пику-образу — форма аппаратной линии: логарифмический сплайн или аналитика (Гауссиан, асимметричный, с хвостовой функцией, Доплер); секции по энергиям в .cpt (ОФ стр. 69–76); - Показать калибровку по эффективности регистрации — просмотр/построение в программе Efficiency (ОФ стр. 76).
  5. Учёт фона: автоматически по конфигурации (поканально или по пикам) либо интерактивно Обработка => Вычесть фон => … (ОФ стр. 77).
  6. Поиск пиков: Обработка => Поиск => Поиск пиков (быстрый, «свертка») или Прецизионный поиск; альтернативы — ручная вставка (Ins) и линии из библиотеки (ОФ стр. 53–54).
  7. Разметка: Обработка => Разметка => Стандартная / По всему спектру (ОФ стр. 55).
  8. Подгонка: Обработка => Подгонка => Подгонка / Подгонка со сшивкой / Раздельная подгонка со сшивкой; тонкая доводка отдельной зоны — Окно подгонки зоны (ОФ стр. 78–79, 106–109).
  9. Идентификация и активность: Обработка => Идентификация и расчет активности (кнопка панели) или Обработка => Расчет активности => <метод>; окно «Информация об активности» — активности, неопределённости, МДА, CID, отчёты (ОФ стр. 79–86). В BG дополнительно кнопки шаблонного/квазишаблонного методов (БГ стр. 8–10).
  10. Отчёт/сохранение: кнопка Отчет в окне активности, Обработка => Отчеты => Печать…, Файл => Сохранить спектр, Файл => Сохранить в базу данных.

4. Как снять площадь пика и её неопределённость

4.1 Автоматический тракт (подгонка модели)

  1. Открыть спектр, убедиться в наличии калибровок (энергия, ПШПВ, пик-образ — файл .cpt в категории конфигурации Подгонка/Калибровки; без пика-образа подгонка невозможна, ОФ стр. 78).
  2. Обработка => Поиск => Поиск пиков и подгонка (F7) — поиск + подгонка за один шаг; либо раздельно: Поиск пиков → Разметка → Подгонка.
  3. Просмотр площадей: - на графике: контекстное меню Пик => Показать площади пиков (ОФ стр. 110); - таблично: Пик => Показать информацию о пиках (Ctrl+P) — окно Параметры пиков со столбцами: Канал ± неопр., Энергия ± неопр., ПШПВ (кэВ/каналы/%), Площадь [импульсы], Неопр. площади (абсолютная), Полная площадь (пик + фон под ним в границах пика из конфигурации), Эффективность ± %, Скорость счета ± неопр., Полная скорость счета, Нуклид, Ступенька, Активность (ОФ стр. 110–111).
  4. Неопределённость площади — результат взвешенного МНК подгонки модели зоны (АО стр. 13–14); отображается в тех же таблицах и отчётах.

4.2 Ручной режим (аналог «ручного ROI»)

  • Вставить пик вручную: указатель на нужный канал → Пик => Вставить фотопик (Ins); границы зоны пика в долях ПШПВ берутся из параметров конфигурации «Границы пиков» (ОФ стр. 110). Спецтипы пиков — через Пик => Вставить пик….
  • Задать/править зону: Зона => Добавить зону (Ctrl+Alt+Z), Разбить, границы мышью.
  • Обработка => Подгонка => Окно подгонки зоны (Ctrl+Alt+M): интерактивная переподгонка зоны с управлением минимизацией (Положение, ПШПВ, Ступенька и её степень, степень полинома фона 0–6 или «Без фона», соотношения интенсивностей); в таблице — Канал, Энергия, ПШПВ, Площадь, Неопр. площади, Ступенька, Нуклид (ОФ стр. 106–108).
  • Площади по Ковеллу: контекстное меню таблицы окна Подгонка зоны → Площади по Ковеллу — пересчёт S_peak = S_ROI − S_background (сумма отсчётов зоны минус фон из полинома), ΔS = √S_peak; при нескольких пиках в зоне площадь делится пропорционально результатам модельной подгонки (ОФ стр. 108; АО стр. 16, разд. 5.2.5).
  • Интегралы по зонам без модели: Зона => Показать информацию о зонах (Alt+Z) — окно Список зон: границы, число пиков, сумма отсчётов в зоне (Площадь), её неопределённость, скорость счёта; сохранение таблицы в текстовый файл или буфер (ОФ стр. 109).
  • Контроль качества подгонки: режим показа отклонений («невязки») — клавиша D (АО стр. 10).

4.3 Куда попадают площади в отчётах

6. Калибровка эффективности и связь с программой Efficiency

  • Кривая эффективности регистрации рассчитывается в отдельной программе Efficiency; из SpectraLine она вызывается пунктом Калибровка => Показать калибровку по эффективности регистрации (режим просмотра эффективности из конфигурации или из спектра с учётом поглощающих слоёв и расстояния; ОФ стр. 76).
  • Форматы (EFF гл. 5, стр. 27–29):
  • .efr — «файл эффективности регистрации»: точки ε(E) по конкретному измерению; секции <детектор>;<геометрия>;<источник> с полями Detector, Geometry, Volume, Density, Material, Thick/DThick, Distance, DistanceCorrection, CorrectionFile (.tc — поправки на истинное суммирование), Layers, списком нуклидов и строками E=Eff,DEff,Nuclide,Area,DArea,Intensity;
  • .efa — «файл кривой эффективности»: секции <детектор>;<геометрия> с теми же паспортными полями, точками и аппроксимацией — ортогональные полиномы зависимости lg(ε) от lg(E) по энергетическим зонам (поля Zones, Zone_N, Curve_N_M), поле EdgeCorrection (K-край);
  • импорт: .ecc (ISOCS Canberra), .txt/.csv построчно «энергия эффективность [неопределённость]» (EFF стр. 5).
  • В конфигурации SpectraLine кривая задаётся параметром Эффективность регистрации (файл .efa) категории Калибровки; выбор конкретной кривой при расчёте — по шифрам геометрии и детектора спектра; в свойствах спектра можно выбрать другую кривую или другой .efa (ОФ стр. 47, 79). В сценарной команде reset упоминается также вариант «.efa или .pol-файл» (СЦ стр. 35).
  • Расчёт эффективности: по файлу источников (.src) при запуске из SpectraLine — идентификация линий аттестованного источника, ε ± Δε по каждой линии; абсолютный и относительный методы; аппроксимация по зонам; пересчёт на плотность материала; применение к спектру (EFF стр. 5–12, оглавление).
  • Учёт различия самопоглощения образца и калибровочного источника — через материалы и БД «Редактора материалов»; при отличии расстояния — коррекция через расстояние до эффективного центра детектора (.efd или константа; ОФ стр. 80).
  • Расчёт эффективности возможен и через EffMaker / Nuclide Master Plus (ОФ разд. 3.4.16, кнопка «Расчет.эфф.» в свойствах спектра, ОФ стр. 47).
  • Расчёт активности при промежуточных уровнях заполнения сосуда — интерполяция между ≥2 кривыми .efa разного объёма, строка VHCorrection={"Coefficient":S,"MaxHeight":MH} добавляется в .efa вручную (ОФ стр. 90–91).

7. Алгоритмы (из «Алгоритмических основ»)

Поиск пиков (АО гл. 3, стр. 8)

  • Быстрый поиск («свертка») — развитие методов Марискотти и Робертсона: свёртка спектра с фильтром на основе второй производной гауссиана; длина фильтра — из калибровки по полуширине; порог — «уровень обнаружения» (рекомендуемое значение 3).
  • Прецизионный поиск — развитие метода Блока: после стандартного поиска и подгонки анализируются невязки, добавляются пики произвольной формы (по пику-образу); высокое разрешение мультиплетов, риск ложных пиков при неадекватной модели.

Разметка (АО гл. 4, стр. 10)

Информативный участок (зона) — один или несколько совместно обрабатываемых пиков; максимальная длина зоны Lzmax — параметр конфигурации; разбиение от больших энергий, точка деления — например по минимуму отсчётов.

Модель спектра и площади пиков (АО гл. 5, стр. 13–15)

  • Отсчёт в канале = фоновая подставка (степенной полином по зоне, степень автоматически из длины зоны) + Σ S_k·ψ(i, p̄_k), где ψ — модельная форма линии (пик-образ), p̄ — положение, ПШПВ, коэффициенты комптоновской ступеньки.
  • Дополнительные уравнения: S_k = A_j·I_jk (связь площади с активностью через интенсивность, скорректированную на эффективность); S_k = S_apriori (фоновые пики); A_k = A_apriori (внешние измерения).
  • Решение — взвешенный нелинейный МНК с разделяемыми параметрами: линейные (коэффициенты фона, площади, активности) решаются линейным МНК (метод Холецкого, LU-контроль вырожденности), нелинейные (положения, ПШПВ, ступенька) — квазиньютоновской итерацией; χ²/n.d.f. ≈ 1 — критерий адекватности, считается и по каждой зоне.
  • Автоматическое исключение нелинейных параметров при плохой статистике: dS/S > 0.05 — не подгонять ступеньку; > 0.1 — не подгонять ПШПВ; > 1.0 — все нелинейные параметры зоны фиксируются.
  • Варианты по зонам (АО стр. 15): Подгонка — зоны независимо, активность нуклида — среднее взвешенное «зоновых»; Подгонка со сшивкой — одна модель по всем зонам (непрерывность модели и фона с первой производной на стыках), одна активность; Раздельная подгонка со сшивкой — общая модель, но активности по зонам с последующим усреднением (учёт хода эффективности).
  • Соотношения интенсивностей: S1/S2 ≈ I1·ε1/(I2·ε2), режимы «внутри участка» и «по всему спектру» (АО стр. 15).
  • Метод Ковелла (АО стр. 16): S_peak = S_ROI − S_bkg; ΔS_peak = √S_peak; для мультиплетов деление площади пропорционально модельной подгонке.
  • Простые методы (первичная калибровка): положения — первые моменты, 5 каналов, 3 канала, перегиб (бета); ПШПВ — геометрический способ, вторые моменты (АО стр. 11–12).

Форма пика и фон (АО гл. 8)

Пик-образ: табличное задание (сплайн в логарифмическом масштабе + обобщённые гиперболы хвостов) либо аналитическое (гауссиан и модификации, Доплер); секции по энергиям, на подгонке — суперпозиция двух ближайших по энергии форм (ОФ стр. 69). Комптоновская ступенька — полином степени −1…3, параметры из подгонки или из пика-образа (ОФ стр. 70, 106). Фоновая подставка зоны — полином степени −1…6.

Идентификация (АО гл. 6, стр. 17–18; гл. 14)

«Ищем пики для линий нуклида, а не линии для пиков»: у нуклида есть характерная линия — линия с минимальной МДА; окно идентификации ΔE = Δ0E·√(E/661), где Δ0E — окно для 661 кэВ (параметр конфигурации; ~1 кэВ ППД, ~10–20 кэВ сцинтилляторы). Три шага: отбор нуклидов по характерной линии → привязка всех линий → выставление недостающих пиков, полезных для точности. Обязательные нуклиды не исключаются (для них — верхний предел активности). Критерии идентификации (гл. 14): статистическая достоверность, полнота, однозначность, принцип наименьшего действия; индекс достоверности CID выводится в результатах (ОФ стр. 81).

МДА и неопределённость активности (АО разд. 6.3, стр. 18–19)

Расчёт по ISO 11929: u(y) = √(w²[u(n_g)² + u(n_0)²] + y²·u_rel²(w)), w = 1/(ε·I/100), u_rel(w) = √(u(ε)² + u(I)²); порог принятия решения y* = k_{1−α}·u(0). МДА — предел детектирования по активности; в отчётах дополнительно вероятность ложного срабатывания, вероятность пропуска, доверительный интервал, наилучшая оценка с границами (ОФ стр. 83).

Прочее

Учёт мёртвого времени и случайных совпадений при высоких загрузках (АО гл. 15; «корр. живое время» в свойствах спектра, ОФ стр. 46); эффективный центр детектора (АО гл. 16); истинное суммирование — .tc-файлы поправок (АО гл. 17; EFF стр. 27); шаблонный метод — МНК-разложение спектра по эталонным спектрам из .etl с матрицей чувствительности (АО гл. 12), квазишаблонный — по стандартным калибровкам без специальной калибровки (АО гл. 13; ОФ стр. 89).

9. Смежные модули одним абзацем

Сценарии (СЦ, 47 стр.) — встроенный командный язык (.lsc): ~100 команд по группам (операции со спектром, калибровка, поиск/подгонка, расчёт активности, библиотека, набор спектра с анализатора, параметры спектра, высокие загрузки, контейнеры, обогащение U / состав Pu, статистические функции), переменные вида $idwin, $library; условные переходы по результатам сравнений (agtlt, sgtlt); пакетные ключи executeforallwin / executeforallspe; запуск с панели Сценарии, из редактора или другого сценария (runscenario); типовое применение — автокалибровка, поточная обработка и сохранение результатов/отчётов без участия оператора.

База спектров (БС, 19 стр.) — модуль работы с БД спектров (DBDll.dll + подключение через SpectraDB.udl, т. е. БД настраиваемая): выборка по датам, типу спектра, детектору, геометрии; просмотр спектров и сохранённых результатов; групповая обработка — усреднение, графики активности и нестабильности; отчёты; выделение/удаление/суммирование спектров и передача обратно в основную программу. Сохранение в базу — Файл => Сохранить в базу данных (спектр + отчёт + результаты).

Efficiency (EFF, 37 стр.) — отдельная утилита расчёта эффективности регистрации и построения аппроксимирующей кривой: запуск из SpectraLine (с передачей результатов поиска пиков) или автономно; расчёт по паспорту эталонных источников (.src) абсолютным и относительным методами, ручной ввод точек, импорт .ecc/.txt/.csv; фильтрация точек, аппроксимация ортогональными полиномами lg ε(lg E) по зонам, коррекция K-края, пересчёт на плотность материала, слияние файлов, просмотр поглощающих слоёв; результат — .efr (точки) и .efa (кривая), применяемые в SpectraLine для расчёта активности.

11.5 NuclearMaterials (ЯМ) — назначение и возможности

  • Назначение: определение изотопного состава плутониевых образцов и степени обогащения урановых образцов гамма-спектрометрией — функциональный аналог задач MGAU/FRAM (документ явно ссылается на корреляционную формулу «используемую в программном обеспечении FRAM» для U-236, ЯМ стр. 9). Поставляется как опция к программам семейства (кроме бесплатной версии и SpectraLineADA): обновление поверх установленной программы либо дистрибутив SpectraLineNM (ЯМ стр. 4).
  • Реализация: два плагина (см. 11.4, п. 5–6) + специальные сценарии и команды сценарного языка recalibrate (перекалибровка по относительной эффективности по самому образцу), xraypatterns (пик-образ лоренц-уширенных рентгеновских линий), showwindow(CompositionPu), showwindow(enrichmentU) (ЯМ стр. 10–11).
  • Плутоний: сценарии Pu_WG_125-600keV (оружейный/высокая доля Pu-239), Pu_RG_125-600keV (реакторный), Pu_RWG_125-450keV (планарный детектор), калибровка Pu_EnergyFW_Calibr; окно «Изотопный состав плутония» — массовые доли с измеренными и декларированными значениями; пересчёт на дату измерения/декларации/сепарации/любую; Pu-242 не измеряется — корреляция f242 = K·f240·f241/f239², декларация или ручной ввод; время выделения — по отношению Pu-241/Am-241 (ЯМ стр. 4–6, 16).
  • Уран: сценарии XRay(Coaxial) (80–185 кэВ), U-GammaRay(Coaxial) (120–2614 кэВ), U-XRay и U_80-258keV (планарный), калибровка U-EnergyCalibration; корреляции для U-236 по формуле МАГАТЭ или FRAM; пересчёт на дату выделения (ЯМ стр. 7–9).
  • Алгоритмы (ЯМ гл. 5, стр. 11–17): две группы методов — «с калибровкой по образцу» (МКО, относительная эффективность из самого спектра) и «внешней калибровки» (МВК); для урана четыре диапазона МКО: 90–100 кэВ (рентген + гамма, только высокое разрешение), 120–350 кэВ (U-238 по 258 кэВ, коррекция случайных сумм, устойчив к экрану), 120–1001 кэВ («сшивка» кривых эффективности по линиям U-235 и U-238, точнее при наличии Th-228), 120–2614 кэВ (рециклированный уран с U-232); отдельно метод бесконечных образцов (InfiniteU.lsc): обогащение по линии 185,7 кэВ через сравнение со стандартным образцом, R = Rc·(S/Sc)·F, с окном «Метод измерения обогащения» (режимы Калибровка/Расчёт, слои контейнера, концентрация U, нейтронный яд) (ЯМ стр. 9–10, 15–16). Для плутония — область 129–800 кэВ (планарный и коаксиальный, экран до 10 мм стали) или 345–800 кэВ (коаксиальный, экран > 10 мм) с относительной эффективностью по линиям Pu-239/Am-241 (ЯМ стр. 16–17).

12.1. Вторичные пики

  • Определение (ОФ стр. 76, разд. 3.4.5.6): «пики одиночного и двойного вылета, пики обратного рассеяния гамма-кванта вне детектора, а также пики "бокового" рассеяния… Такого рода пики мы назовем вторичными». Полный перечень типов линий — 10 (редактор библиотеки, ОФ стр. 42): гамма, рентген, аннигиляционная, край Комптона, обратное рассеяние, боковое рассеяние, одиночный/двойной вылет, случайное суммирование, доплеровски уширенная; у каждой — признак учёта в обработке. Те же типы — секции пика-образа (ОФ стр. 70, 224).
  • Настройка: категория конфигурации «Вторичные пики» (ОФ стр. 28, 204): флаги по типам + коэффициенты A/B случайного суммирования; калибровка — файл .cap (формат ОФ стр. 186–187): по монолиниям хранится «отношение площади вторичного пика к площади пика полного поглощения в поле Intensity».
  • Механизм (ОФ стр. 76–77): для каждого идентифицированного ППП вычисляются энергия и априорная площадь вторичного пика; на месте наложения площадь делится: если пик спектра больше априорного — остаток S−Sa считается самостоятельным ППП; если меньше — ППП удаляется, остаётся вторичный. При заданном .cap вся информация берётся из него; типы вне .cap не учитываются даже при включённых флагах.
  • По умолчанию: явной фразы в доках нет ⚠️, но в образцовом Lsrm.cnf (HPGe 20 %) все флаги нулевые: ConsiderInstrumentalPeaks/BackScattering/SideScattering=0 (ОФ стр. 167), XEscCorrection/UseSingleEscape/UseDoubleEscape/UseTrueSummation=0 (стр. 168) — в поставке обработка вторичных выключена.
  • В активность не идут (ОФ стр. 76): «для идентификации и расчета активности вторичные пики обычно не используются»; в результатах группируются в псевдонуклид Secondary (ОФ стр. 82); показ — флаг «Показать специальные нуклиды» (стр. 85). Ручная вставка спецпиков — «Пик → Вставить пик…» (стр. 110).

12.2. Комптоновский континуум

  • Модель зоны: полином фоновой подставки (степень авто) + пики; в векторе нелинейных параметров — «коэффициенты для расчета комптоновской ступеньки» (АО стр. 13–14); при dS/S > 0.05 подгонка ступеньки отключается.
  • Ступенька — часть пик-образа: нормированные на площадь коэффициенты C′L = CL/S хранятся в .cpt и переносятся на другие линии (АО стр. 31); три режима категории Подгонка: фитуемая / из пика-образа / без ступеньки (ОФ стр. 29–30, 107).
  • Межнуклидного вычета комптона в пиковом тракте НЕТ: континуум чужих нуклидов поглощается полиномом подставки зоны; перекрытие фотопиков решается совместным МНК S_i = Σ A_j·Y_ji (АО стр. 22–23). Единственный «коэффициентный» механизм континуума — тип Compton в .cap: максимум комптоновского распределения вставляется широким вторичным пиком (пример 661 кэВ: Intensity=40, полуширины 11 ПШПВ — ОФ стр. 187).
  • Шаблонный метод учитывает полный отклик (включая комптон) столбцами матрицы чувствительности по чистым эталонам (АО стр. 41–42); квазишаблонный — фотопики из библиотеки + одна общая комптоновская подложка по самому спектру (АО стр. 44).

12.3. Прецедент отказа от прямого вычета площадей (ключевое)

АО стр. 38–39 (разд. 9.3): вычитание фоновых вкладов из площадей пиков S′ = S − S_f·(t/t_f) признано «не всегда корректным» при частичном перекрытии пиков — «в нашем программном обеспечении она уже не используется»; с версии 1.6 заменено выставлением фоновых линий с априорными скоростями счёта прямо в модель подгонки. Прямой прецедент к обсуждению Reference-вычетов ROI BecqMoni: ЛСРМ прошёл путь «вычет площадей» и ушёл от него в модельный фит.

12.4. Смежное

  • Априорная информация — штатный канал: члены априорных площадей и активностей в χ²-функционале (АО стр. 13–14), меню «Априорная информация» (ОФ стр. 192), метод «Последовательный по зонам (расширенный)» протаскивает активности между зонами (АО стр. 24).
  • Фоновые пики — тот же механизм априорных площадей; метятся background, активность не считается (АО стр. 39; ОФ стр. 82).
  • Истинное суммирование — поправка интенсивностей (.tc, TccfCalc), не вычет пика (ОФ стр. 26; АО стр. 51–54); случайное — коэффициенты A/B в формуле активности (АО стр. 7, 48).
  • Признак «n» у линии «искусственно увеличивает неопределённость её интенсивности» — мягкое выключение сомнительной линии (АО стр. 21).
  • Несоответствие доков: формат описан как .cap (ОФ стр. 186), а пример конфигурации ссылается на .csp (стр. 167); маппинг GUI-вкладки на секции .cnf не сведён.
  • Метрика «Отношение пик-Комптон» (ОФ стр. 98): высота 1332,5 кэВ к среднему счёту 1040–1096 кэВ.
