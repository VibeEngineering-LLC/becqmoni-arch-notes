BecqMoni ↔ SpectraLine(BG): сравнительный анализ архитектуры, функционала и алгоритмов

Дата: 30.07.2026. Материал к обсуждению архитектурного рефакторинга BecqMoni (PR #32).

Источники: BecqMoni — код ветки roi-wizard-reworked @ d80c7ee (адреса файл:строка сверены по дереву); SpectraLine — конспект документации ЛСРМ SPECTRALINE-BG-NOTES (со страницами PDF); NuclideMaster — конспект NUCLIDEMASTER-NOTES. Утверждения о SpectraLine — по документации (кода нет); утверждения о BecqMoni — по коду.

1. Архитектура: сущности и их хранение

Сущность SpectraLine (LSRM) BecqMoni сейчас Комментарий для рефакторинга
Прибор Конфигурация .cnf + Lsrm.ini; локальная копия конфигурации создаётся на каждый спектр (ОФ стр. 44) DeviceConfigInfo в XML, FormatVersion="120920" жёсткий гейт (DeviceConfigManager.cs:82) У LSRM «копия конфигурации при спектре» решает воспроизводимость задним числом
Геометрия измерения Первоклассное понятие: шифр геометрии в заголовке .spe (GEOMETRY, DISTANCE), секции <детектор>;<геометрия> в .efr/.efa; выбор кривой — по шифрам детектора и геометрии спектра (ОФ стр. 47, 79) Сущности нет (grep Geometry = 0); геометрию изображает целый ROI-файл с вмороженными коэффициентами Ключевой разрыв. Модель arch-документа BecqMoni (Device 1:N геометрий) = модель LSRM
Кривая эффективности Отдельные файлы: .efr (точки по измерению) и .efa (аппроксимация lg-lg ортогональными полиномами по зонам); строится отдельной программой Efficiency; на любую геометрию — своя секция ROIEfficiency внутри ROI-конфига; привязка прибора — один EfficencyROIGuid (не проставлен ни в одном из 9 поставочных устройств); Dose-вкладка грузит свою транзиентную копию У LSRM кривая — самостоятельный артефакт со своим паспортом (материал, плотность, слои, расстояние)
Библиотека нуклидов .lib (редактируется NuclideMaster; ENSDF + ССД Росстандарта); библиотека ≠ зоны ≠ эффективность NuclideDefinition/NuclideSet в одном XML без FormatVersion; цепочка — конвенцией в скобках имени Роли совпадают; у BecqMoni цепочка неформализована (предмет пункта 1 письма)
Область счёта (окно) Прямого аналога нет. Зоны (.zon) — продукт автоматической разметки вокруг найденных/отмеченных пиков, границы от формы пика/мультиплета, живут внутри цикла фита, к нуклиду не привязаны (АО гл. 4) ROI-записи: заранее прошитые границы под нуклид + примитивы (BG difference) + замороженный Bq-коэффициент (ROIConfigForm.cs:957; потребление MeasurementResultManager.cs:44) BM-ROI — идеология аппаратного радиометра (окна прошиты методистом), не спектрометрического пакета; в SL такого тракта нет и не нужно
Спектр-документ .spe (заголовок KEY=VALUE: времена, геометрия, детектор, массы, калибровки, пики, зоны + бинарный спектр); .spef — «спектр со всеми данными» (конфигурация, пик-образ, зоны, фон, библиотека, паспорта, эффективность в одном файле) .bmn с ROIConfigReference.Guid (ссылка, не копия; DocumentManager.cs:1375) .spef — готовый ответ на вопрос воспроизводимости: сохранять с измерением ВСЁ использованное. У BecqMoni — ссылка по Guid, осиротение возможно
Эталоны Паспорта источников .src, эталонные спектры .etl (шаблонный метод) Понятия нет (дозовая калибровка по эталонному спектру внутри DeviceConfig) —
Доза Матрица дозы .doz; отдельный тракт 16 точек µ_en и R→Sv захардкожены в WinForms-форме (DeviceConfigForm.cs:2522-2577); doseRateCoeff — локальная переменная, размазана по точкам калибровки Пункт 3 arch-документа BecqMoni; подтверждено кодом

3. Алгоритмы (ядро расчёта)

Алгоритм SpectraLine (АО = «Алгоритмические основы») BecqMoni Комментарий
Модель зоны Полином фона (степень авто из длины зоны) + Σ S·ψ(пик-образ) + комптоновская ступенька (полином −1…3); взвешенный нелинейный МНК, разделяемые параметры: линейные — Холецкий, нелинейные — квазиньютон; χ²/ndf по зоне (АО стр. 13-15) Гауссианы + линейная подложка в окне фита; примитивы вычитания в ROI-методе SL решает всю зону совместно; BM — окно вокруг линии
Защита от плохой статистики Автофиксация параметров: dS/S>0.05 — не подгонять ступеньку; >0.1 — не подгонять ПШПВ; >1.0 — фиксировать все нелинейные Пороговые отсечки фиттера Приём SL «деградировать модель по статистике» — переносим
Площадь и её σ Из МНК; альтернативно Ковелл: S = S_ROI − фон, ΔS = √S; мультиплет — деление пропорционально модельной подгонке ROI: сумма минус примитив; фиттер: площадь гауссиана При сверке площадей между инструментами следить за определением площади (net против окна)
Связь площадей с активностью Совместные уравнения S_k = A_j·I_jk прямо в МНК (сшивка зон, одна активность на нуклид) Активность отдельно от фита: ROI-коэффициент или пересчёт площади В SL активность — параметр фита; в BM — постобработка
Соотношения интенсивностей S1/S2 ≈ I1·ε1/(I2·ε2) как ограничение фита Аналог — veto по согласованности цепочки с EfficiencyShape Идея одна: форма ε(E) дисциплинирует набор линий
Эффективность ε(E) из .efa; выбор по шифрам геометрия+детектор; самопоглощение через БД материалов; эффективный центр .efd; истинное суммирование .tc (TCCFCALC) ε(E) внутри ROI-конфига; поправок на суммирование и самопоглощение нет .tc-поправки LSRM считает Монте-Карло (EffCalcMC)

4. Выводы для рефакторинга BecqMoni (кратко)

  1. Модель «Device (1:N геометрий) / ROI (окна) / NuclideSet (библиотека)» из arch-документа BecqMoni — это фактически модель LSRM, проверенная промышленной практикой. Спор о направлении закрыт референсом.
  2. LSRM отвечает и на вопрос воспроизводимости (В1): локальная копия конфигурации при спектре + формат .spef «спектр со всеми данными». Перевод на «коэффициент в момент расчёта» обязан сопровождаться заморозкой использованных ε/I/кривой в результате измерения.
  3. Кросс-device ROI (В2): у LSRM границы зон живут в спектре и конфигурации конкретного тракта, а не в универсальном файле; универсальность у них достигается тем, что зона не хранит ничего приборного. Для BM: либо границы в долях ПШПВ, либо честное «в пределах класса детекторов».
  4. Формат .efa/.efr (паспорт кривой: детектор, геометрия, материал, слои, расстояние) — образец того, чем должна стать сущность «геометрия» в BM.
  5. Дешёвые переносы идей SL в BM: √E-окно идентификации, автодеградация модели по статистике, отчёт ISO 11929, паспортные поля кривой.
  6. BecqMoni уникален тем, что несёт ОБА тракта: радиометрический (ROI — прошитые окна, «Бк одной кнопкой», работает при слабой статистике) и спектрометрический (NuclideSet + фиттер). У SL радиометрического тракта нет. Предложенный рефакторинг не убирает эту двойственность, а впервые честно её оформляет: ROI = радиометр, NuclideSet = спектрометр, Device = прибор с геометриями.

5. Статус согласования (30.07.2026)

Документ arch/architecture-refactor.md в ветке roi-wizard-reworked закрыл вопросы геометрии (выбор в SampleInfo, умолчание в конфиге устройства) и дозы (геометрия прибора вместо одноразового загрузчика). Открытыми остаются два пункта настоящего анализа: снапшот использованных величин (ε, I, геометрия) в сохраняемом результате измерения — иначе смена кривой или библиотеки молча меняет прошлые числа; и переносимость границ ROI между классами детекторов (вывод 3).
